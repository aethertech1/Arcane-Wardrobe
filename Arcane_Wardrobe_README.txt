THE ARCANE WARDROBE — QUICK START
by aether_tech & chatgpt

The Arcane Wardrobe is a browser-based equipment catalog for wearable items.
No installation, Python, or internet connection is needed for its core features.

GETTING STARTED
1. Keep arcane_wardrobe.html and your item CSV in a convenient folder.
2. Double-click arcane_wardrobe.html to open it in a modern web browser.
3. Click Data / CSV at the top, then Import to load your item database.
4. Click the top Wardrobe button to return to the equipment view.

THE WARDROBE
- Hover over the mannequin or a body-location button to browse items.
- Click a location to lock its list; click again to unlock it.
- Use the Collection search, source-book selector, and filters to find items.
- On an item row, use Info for details, the star to save it, Equip/Unequip
  to put it on the mannequin, or Edit to change its database entry.
- The Saved view lists bookmarked items from all locations together.
- Hands and Fingers are separate; rings belong under Fingers.
- Equipped List shows all equipped items in one popup.
- Export Equipped creates a PDF or JPG equipment sheet.

DATA / CSV
- Import loads a catalog; Export Edited CSV downloads your changes.
- Add, edit, or delete items using the Database Editor or item cards.
- Search and filter by location, attunement, or rarity. Sort by item name,
  rarity, or source, and drag column dividers to resize the table.
- The Text Size menu adjusts how large database-row text appears.
- The CSV uses # as its field separator, with these columns:
  Item Name # Body Location # Rarity # Attunement # Source # Description
  An optional seventh column holds the D&D Beyond item URL.
- When a D&D Beyond link exists, its item card can open that listing.

CHARACTER EQUIPMENT IMPORT (OPTIONAL)
- In Data / CSV, click Import Character to compare a D&D Beyond character's
  main Equipment inventory against the current catalog.
- Try the public character link, or load/paste character JSON if direct
  access is blocked by the browser. Other containers are excluded when
  the character data identifies them.
- Review matches and unmatched items. You can add unknown items to the
  catalog; Apply equipped items updates the mannequin only when clicked.

IMPORTANT: Catalog changes remain in the current browser tab until you
click Export Edited CSV and save the downloaded file. Saved stars and equipped
selections are stored separately in your browser; keep CSV backups.
